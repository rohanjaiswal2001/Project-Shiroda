# Project Shiroda

A private invitation page for an ultra-luxury golf and wellness estate near Shiroda, Sindhudurg.

- `index.html`: the whole page (styles and scripts inline)
- `img/`: the twelve plates as WebP

All images are artist's impressions. The page is set to `noindex` so search engines skip it.

## Updating

Edit `index.html` or replace an image in `img/` with the same file name, then commit to `main`. GitHub Pages republishes within a minute or two.

## Interest form

Fill in `SUPABASE` near the bottom of `index.html` (project URL and publishable key) to collect submissions in a Supabase table called `interest`. Until then, submissions stay in the visitor's browser only.
